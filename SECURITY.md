# Beveiligingsbeleid

## Een kwetsbaarheid melden

Heb je een beveiligingsprobleem gevonden in deze website of in de code? Meld het dan **vertrouwelijk** via GitHub:

**[Een kwetsbaarheid melden](https://github.com/mikemadern/marielle-madern/security/advisories/new)**
(op de repository: tabblad *Security* → *Report a vulnerability*)

Je melding blijft zo privé totdat er een oplossing is. Maak voor een beveiligingsprobleem **geen** openbaar issue of pull request aan.

Beschrijf zo goed mogelijk wat je hebt gevonden, waar (pagina of bestand), hoe wij het kunnen nabootsen en wat volgens jou de impact is.

## Wat je kunt verwachten

Deze website wordt in vrije tijd onderhouden. Daarom:

- We streven ernaar binnen **7 dagen** te reageren.
- We houden je op de hoogte van de voortgang en laten het weten zodra het is opgelost.
- We vragen je het probleem niet openbaar te maken voordat er een oplossing is. We stemmen dat samen met je af.
- Wil je in de oplossing genoemd worden? Laat het weten. Er is geen bugbounty of andere beloning.

## Welke versie

Alleen de actuele code op de `main`-branch, en de website die daaruit wordt gepubliceerd, wordt bijgewerkt. Er zijn geen aparte releases of oudere versies met ondersteuning.

## Scope

**Binnen scope:** de code in deze repository (de Nuxt-website) en de afhankelijkheden daarvan.

De site bestaat uit vooraf gegenereerde, statische pagina's: zonder inlog, zonder eigen backend en zonder betalingsverwerking. Contact opnemen en bestellen gaat via een link die het e-mailprogramma van de bezoeker opent.

**Buiten scope:**

- Websites en diensten die niet uit deze repository komen (bijvoorbeeld Spotify, YouTube, Adobe Fonts, GitHub en de hostingdienst). Meld problemen daar bij de betreffende partij.
- Denial-of-service- of andere volume-aanvallen, spam, phishing of social engineering.
- Geautomatiseerde scanrapporten zonder aantoonbare impact.

## Geen beveiligingsprobleem?

- **Vraag over je gegevens?** Zie de pagina *Privacy* op de website.
- **Andere vragen?** Gebruik de pagina *Contact* op de website.

---

## English summary

If you found a security issue, please report it privately via GitHub (*Security* tab → *Report a vulnerability*) and do not open a public issue or pull request. This site is maintained in spare time: we aim to respond within 7 days, and there is no bug bounty. Only the current `main` branch is supported.
